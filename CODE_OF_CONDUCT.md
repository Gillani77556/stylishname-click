# Code of Conduct

This project follows a simple standard: be respectful, be constructive,
and keep discussion about the work.

- Welcome newcomers; explain, don't mock.
- Critique code and ideas, never people.
- No harassment, discrimination, spam or self-promotion.
- Maintainers may remove comments, issues or pull requests that break
  these rules, and may block repeat offenders.

Report problems by opening an issue, or contact the maintainer through
https://www.stylishname.click/ if the matter is private.
